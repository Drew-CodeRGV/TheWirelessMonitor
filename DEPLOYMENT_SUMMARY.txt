🎯 DEPLOYMENT STEPS:

1️⃣  Configure AWS Credentials (5 minutes)
   └─ Run: ./setup_aws_credentials.sh
   └─ You'll need: AWS Access Key ID + Secret Access Key
   └─ Get from: https://console.aws.amazon.com/iam/

2️⃣  Run Deployment Script (10 minutes)
   └─ Run: ./deploy_to_lightsail.sh
   └─ Script creates everything automatically
   └─ You'll be prompted to add DNS record

3️⃣  Add DNS Record (2 minutes)
   └─ Type:  A
   └─ Name:  signal
   └─ Value: [IP shown by script]
   └─ Where: Your DNS provider for wirelessnerd.net

4️⃣  Wait for SSL (2-5 minutes)
   └─ Caddy automatically gets Let's Encrypt certificate
   └─ Site will be live at https://signal.wirelessnerd.net
